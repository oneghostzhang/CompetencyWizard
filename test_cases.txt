CompetencyWizard 測試資料檔
用途：測試 v2.2.0 六頁流程，重點覆蓋長駐 LLM Worker 與逐任務即時分析
版本：v2.2.0
建立日期：2026-05-15
================================================================================

操作步驟（每個測試案例共通）：
  1. [搜尋頁]    輸入職業名稱 → 搜尋職能基準 → 勾選最符合的基準
  2. [編輯器頁]  確認任務列表，調整職能等級，按「下一步：填寫工作詳情 →」
  3. [詳細填寫頁] 逐任務填入「工作描述」與「工作產出」
                 → 每次儲存（按下一個任務或上一個任務）後，右上角 badge 應變為 ●分析中
                 → 稍後應自動更新為 ✓已完成（模型載入完成後）
                 → 每個任務可在 「AI 分析框架」ComboBox 獨立選擇框架
  4. [LLM建議頁] 進入時部分任務可能仍顯示「●AI 分析中，請稍候...」，
                 結果回來後自動填入核取方塊與框架標籤
                 → 勾選/取消行為指標，按「確認採用 →」
  5. [補充說明頁] 填入補充說明，按「匯出 Excel 職能說明書」

新版 Badge 狀態說明：
  ● 未提交（灰）  — 描述為空或從未存檔
  ● 分析中（橙）  — 已提交給 Worker，等待結果
  ✓ 已完成（綠）  — LLM 結果已回傳
  ↻ 需更新（藍）  — 描述修改後尚未重新提交

【TC-01】主路徑 + AUTO 框架（會計助理）
================================================================================
測試重點：完整六頁主路徑；AUTO 模式下各任務框架標籤是否正確顯示；
          進入建議頁時部分任務已完成、部分仍在分析中的動態填入效果。

搜尋字串：會計助理
預期選擇：[FAC3313-001v2] 會計助理（相似度最高）

── 編輯器頁確認 ──────────────────────────────────────────────
  預期任務列（PDF 解析正確時 T1~T4 全部出現）：
    T1  T1.1  製作與維護各項交易記錄
    T2  T2.1  核對交易憑證之正確性
    T3  T3.1  執行帳務相關計算工作
    T4  T4.1  協助編製各類財務報表
  職能等級設為 2

── 詳細填寫頁（框架全部維持 AUTO）──────────────────────────
  ★ 每填完一個任務，觀察右上角 badge 變化：儲存後應從「●未提交」→「●分析中」

[T1.1] 製作與維護各項交易記錄

  工作產出：
    已登錄傳票清單、已歸檔憑證、月結傳票彙整表。

[T2.1] 核對交易憑證之正確性
  框架：AUTO（預設）
  工作描述：

  工作產出：
    已核對憑證（蓋驗章）、差異清單（若有）。

[T3.1] 執行帳務相關計算工作
  框架：AUTO（預設）
  工作描述：

    協助計算員工加班費明細，確認數字與出缺勤系統一致。
  工作產出：
    每日現金日記簿、加班費計算明細。

[T4.1] 協助編製各類財務報表
  框架：AUTO（預設）
  工作描述：
    月底依照主管指示，從系統匯出日/月/季財務數據，
    填入報表範本，進行簡單彙整（不含分析），交主管審閱。
  工作產出：
    月財務報表初稿（損益表、資產負債表）、各類申報書輔助表。

  ・所有任務完成後，每個 GroupBox 右上角顯示 ABCD / 5W2H / STAR 其中之一的彩色標籤
  ・進度條最終應達 4/4

  工作產出：

  工作產出：
    資安事件報告、數位鑑識記錄、CERT 通報文件。

[任務三] 資安政策維護與人員教育訓練

  工作產出：

================================================================================
測試重點：詳細填寫頁右上角 badge 在三種狀態下的切換是否正確；

  4. 記錄從第一次儲存到 badge 變綠的等待時間（= 模型載入 + 推論時間）
